## Classificação de Dados
Identificar e categorizar dados pelo nível de sensibilidade e impacto para a organização.

| Nível        | Descrição                        |
| ------------ | -------------------------------- |
| Público      | Acesso irrestrito                |
| Interno      | Uso exclusivo da organização     |
| Confidencial | Dados sensíveis, gera prejuizo   |
| Restrito     | Informação Crítica, danos graves |

## Proteção Proporcional
Proteção proporcional ao nivel de sensibilidade do dado.

## Governança de Dados
Define regras corporativas e implementa diretrizes de proteção no ambiente fisico e tecnologico.
