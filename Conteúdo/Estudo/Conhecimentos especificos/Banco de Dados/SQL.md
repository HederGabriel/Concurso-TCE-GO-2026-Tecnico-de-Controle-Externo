# SQL - Structured Query Language
Linguagem de consulta estruturada, uma linguagem padrão de gerenciamento de dados

- DDL (Data **Definition** Language)
- DQL (Data **Query** Language)
- DML (Data **Manipulation** Language)
- DCL (Data **Control** Language)
- DTL ou TCL (Data **Transation** Language ou Transation Control Language)

## DDL
> Definir
- CREATE
- DROP
- ALTER
- TRUNCATE
- COMMENT
- RENAME

## DQL
> Buscar
- SELECT

## DML
> Manipular
- INSERT
- UPDATE
- DELETE
- CALL
- EXPLAIN PLAN
- LOCK TABLE

## DCL
> Controle
- GRANT
- REVOKE

## DTL ou TCL
> Transação
- COMMIT
- SAVEPOINT
- ROLLBACK
