# Álgebra Relacional
Forma teórica de especificar operações sobre os dados usando o modelo relacional
- Usuários especificam os dados e programadores especificam os comandos necessários
- Entrada: uma ou duas relações
- Saída uma nova relação, como resultado

## Operações
- Unárias
  + [σ - Seleção]()
  + [π - Projeção]()
  + [ρ - Renomeação]()
- Binárias
  - X - Produto cartesiano
  - |x| - Junção
  - Operações sobre conjuntos
    + ∪ - União
    + '-' - Diferença
    + ∩ - Interseção
