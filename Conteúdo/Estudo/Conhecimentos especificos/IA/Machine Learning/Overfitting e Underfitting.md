# Overfitting e Underfitting

## Overfitting
é quando o modelo **aprende demais sobre os dados de treino** (apresentando resultados execelentes), PORÉM a performance do modelo **cai drasticamente com dados de teste** (sobreajuste entre modelo de treino e teste)

## Underfitting
é quando o modelo **não conseguiu aprender o suficiente** sobre os dados. Ele acontece quando o **erro do modelo é elevado em ambos os dados de treino e de teste**.
