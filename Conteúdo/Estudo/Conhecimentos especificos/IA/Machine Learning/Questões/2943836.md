[#2943836](https://www.tecconcursos.com.br/questoes/2943836) [FGV](https://www.tecconcursos.com.br/bancas/fgv) - [2024 - Auditor de Controle Externo (TCE-GO)/Tecnologia da Informação](https://www.tecconcursos.com.br/concursos/auditor-de-controle-externo-tcego-tecnologia-da-informacao-2024)

Os modelos de aprendizado de máquina desempenham um papel fundamental na análise e interpretação de dados em uma variedade de domínios.

Uma característica dos modelos de aprendizado de máquina supervisionados e não supervisionados é que modelos supervisionados:
A) exploram a detecção de outliers, enquanto modelos não supervisionados usam dados representados em formatos como XML ou JSON para treinamento.. <br>
B) geralmente têm menos tendência ao overfitting do que modelos não supervisionados. <br>
C) requerem dados rotulados para treinamento, enquanto modelos não supervisionados podem funcionar com dados não rotulados. <br>
D) são mais adequados para tarefas de análise exploratória de dados, enquanto modelos não supervisionados são mais adequados para previsão de séries temporais. <br>
E) são usados apenas para classificação, enquanto modelos não supervisionados são usados apenas para agrupamento.

---
Resposta: C ✅
Gabarito: C ✅
