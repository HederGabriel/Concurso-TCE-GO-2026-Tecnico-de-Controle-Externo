# Aprendizado Supervisionado
Nesta modalidade, o algoritmo aprende a partir de dados que já possuem rótulos ou resultados conhecidos.
- **Classificação** de imagens: Quando o sistema recebe imagens de objetos (como flores ou celulares) já identificados para aprender a reconhecê-los.
- **Regressão**: O ajuste de uma curva que melhor explica a relação entre variáveis onde os resultados esperados já estão estabelecidos.

## Palavras Chaves
- Classificação
- Regressão

## Modelos
- Árvore de decisão
- Regressão linear
- Regressão logística
- Rede neural artificial (RNA)
- K-Vizinhos mais próximos (KNN)
- Máquina de vetores de suporte (SVN)
