# Naive Bayes

Algoritmo de **Machine Learning** utilizado para classificação, baseado no Teorema de Bayes.

Calcula a probabilidade de um elemento pertencer a determinada classe, considerando suas características.

**## Característica principal**
Assume que as características analisadas são **independentes** entre si.

**## Aplicações**
- Detecção de spam.
- Análise de sentimentos.
- Classificação de textos.
- Diagnósticos probabilísticos.
