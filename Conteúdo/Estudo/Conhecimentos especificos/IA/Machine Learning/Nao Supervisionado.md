# Aprendizado Não Supervisionado
Aqui, o modelo não recebe informações prévias ou rótulos. A tarefa do algoritmo é descobrir sozinho as relações e padrões ocultos nos dados para agrupá-los (**Clusterização**).

## Palavras Chaves
- Clusterização
- Associação

## Ex:
- **Agrupamento de plantas**: Categorizar diferentes espécies com base em características físicas (como tamanho do caule ou folhas) sem saber previamente quais são os grupos 
- **Segmentação de clientes**: Identificar perfis de consumo dentro de um grande conjunto de dados de clientes, encontrando semelhanças e proximidades entre eles

## Modelos
- K-means
- Análise de componentes principais (PCA)
- Agrupamento hierárquico
