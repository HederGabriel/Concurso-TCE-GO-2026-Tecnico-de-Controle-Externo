# SSH - Secure Shell

Protocolo de rede que permite **acesso remoto seguro** a computadores por meio de uma conexão criptografada.

- **Camada:** Aplicação.
- **Porta padrão:** 22.
- **Segurança:** criptografia, autenticação e integridade dos dados.

> Permite executar comandos e administrar computadores remotamente de forma segura.

## Telnet - Teletype Network

Protocolo utilizado para acesso remoto a computadores.

- **Porta padrão:** 23.
- **Segurança:** não utiliza criptografia.

> Considerado inseguro, pois transmite dados, incluindo credenciais, em texto puro.

**SSH substituiu o Telnet** como alternativa segura para acesso remoto.
