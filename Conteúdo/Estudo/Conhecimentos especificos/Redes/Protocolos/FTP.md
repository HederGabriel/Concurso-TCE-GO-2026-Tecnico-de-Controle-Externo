# FTP - File Transfer Protocol

Protocolo utilizado para **transferência de arquivos** entre um cliente e um servidor.

- **Camada:** Aplicação.
- **Portas padrão:** 20 (dados) e 21 (controle).
- **Download:** transferência de arquivos do servidor para o cliente.
- **Upload:** transferência de arquivos do cliente para o servidor.

> Não utiliza criptografia por padrão, transmitindo dados e credenciais em texto puro.
