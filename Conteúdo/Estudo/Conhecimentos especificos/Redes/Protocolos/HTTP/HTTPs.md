# HTTPS - Hypertext Transfer Protocol Secure

Protocolo de comunicação que utiliza **TLS** para fornecer segurança ao HTTP.

- **Camada:** Aplicação.
- **Porta:** 443 (HTTPS).
- **Porta HTTP:** 80 (sem criptografia).

**HTTP + TLS = HTTPS**

## TLS - Transport Layer Security

Protocolo criptográfico responsável por proteger as comunicações, fornecendo:

- **Confidencialidade:** impede a leitura dos dados por terceiros.
- **Integridade:** impede alterações não autorizadas nos dados.
- **Autenticação:** permite verificar a identidade do servidor.

> É o protocolo de segurança utilizado atualmente pelo HTTPS.

## SSL - Secure Sockets Layer

Protocolo antecessor do TLS, desenvolvido para fornecer segurança às comunicações por meio de criptografia.

> Foi substituído pelo TLS e está obsoleto.
