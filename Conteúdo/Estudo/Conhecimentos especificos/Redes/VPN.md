# VPN - Virtual Private Network

Tecnologia que estabelece uma **conexão privada e segura através de uma rede pública**, utilizando criptografia e tunelamento para proteger a transmissão de dados.

- **Função:** estabelecer conexões seguras entre dispositivos ou redes.
- **Segurança:** criptografia, autenticação e integridade.
- **Utilização:** acesso remoto e comunicação segura entre redes.

> Permite que um usuário acesse uma rede privada remotamente, como se estivesse conectado diretamente a ela.

## Funcionamento da VPN

1. O dispositivo estabelece uma conexão com um servidor VPN.
2. É criado um **túnel criptografado** entre os pontos.
3. Os dados são encapsulados e transmitidos pela rede pública.
4. O destino recebe os dados e realiza a comunicação.

## Tipos de VPN

- **Site-to-Site:** conecta duas ou mais redes privadas por meio de uma rede pública.
- **Remote Access (Acesso Remoto):** permite que um usuário se conecte remotamente a uma rede privada.

## Protocolos de VPN

- **IPsec:** conjunto de protocolos que fornece segurança na comunicação IP.
- **SSL/TLS VPN:** utiliza TLS para estabelecer conexões seguras.
- **WireGuard:** protocolo moderno de VPN, com foco em simplicidade e desempenho.
- **OpenVPN:** solução de VPN que utiliza SSL/TLS.
