# **SaaS — Software as a Service**
**Software como Serviço**

- Fornece aplicações prontas para uso, geralmente acessadas pela internet.
- O software é hospedado e mantido pelo provedor.
- O provedor gerencia toda a infraestrutura, a plataforma e a aplicação.
- O cliente utiliza o software, podendo realizar configurações e gerenciar seus próprios dados.

**Exemplo:** Gmail, Google Docs e Microsoft 365.
