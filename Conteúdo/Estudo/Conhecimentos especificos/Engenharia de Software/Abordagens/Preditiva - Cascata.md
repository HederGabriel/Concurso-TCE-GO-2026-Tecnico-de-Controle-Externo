# Abordagem Preditiva
é uma forma linear de conduzir projetos onde um plano é criado e neste é registrado tudo o que será realizado antes da execução.

## Características
- Estágios sequenciais de desenvolvimento
- O trabalho com requisitos constitui parte fundamental para a execução das demais fases
- O software é testado para se verificar se está em conformidade com seus requisitos e design.
- É creditado a Winston Royce a criação deste modelo
- BRUF -> Big Requirements Up Front = grande levantamento de requisitos antecipado
- **Escopo FIXO**
- Custo para desfazer o erro é elevado
- Entregas isoladas não agregam valor para o usuário
> MUITA INCERTEZA no inicio do planejamento
