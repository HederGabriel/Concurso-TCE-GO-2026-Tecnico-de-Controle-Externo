# Engenharia de Contexto
É a construção de sistemas dinâmicos para fornecer as informações e ferramentas certas no formato certa para que o [LLM](llm.md) possa realizar a tarefa de forma plausível. 

> Na maioria das vezes, quando um agente não tem um desempenho confiável, a causa subjacente é que o contexto, as instruções e as ferramentas apropriados não foram comunicados ao modelo.

## RAG (Retrieval-Augmented Generation)
Uso de bases de dados para recuperar apenas informações relevantes para a tarefa.

## Memória Semântica
Implementação de uma "ferramenta" de memória que permite ao agente aprender sobre o usuário ao longo do tempo.
