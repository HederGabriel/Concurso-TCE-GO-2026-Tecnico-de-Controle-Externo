# Distribuições (Distros)
Uma distribuição Linux é um sistema operacional feito do kernel Linux, versões de servidor e de desktop.

Atualmente existem cerca de 600 distros ativas do Linux. As mais comuns são:
- **Ubuntu**: 
  + Empresa: Canonical
  + Derivado do Linux Debian (distro)
  + Interfaca: Gnome

- **Fedora**: 
  + Flexível e Poderoso
  + Baseado no Red Hat

- **Mint**:
  + Criado a partir de uma comunidade baseada no Ubuntu

# Gerenciadores de Pacotes
- Apt
  + para sistemas **baseados no Debian**
  + Conjunto com dpkg
  + Fácil de atualizar, instalar e remover software
  + EX: `apt-get update`

- YaST
  + Pode ser usado a partir de uma inteface baseada em texto **(TUI)** ou uma interface gráfica completa **(GUI)**
  + Utilizado no **Open Suse**

- YUM
  + para distros que utilizam o **RPM**
  + Criado pela **REDHAT**
  + Utilizado por distro baseadas em **REDHAT**
  + Fedora, CentOS...
